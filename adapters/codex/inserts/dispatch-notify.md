In Codex nothing brings you back when a process exits. Start the `wait` line with `exec_command` and no `--timeout`: the call yields after at most 30 s with the process still running and returns its `session_id`. Then poll it with `write_stdin`, empty `chars` and `yield_time_ms` 300000, which returns when the process exits or the window closes; repeat while it is still running. A message the user sends is read after the running poll returns.
